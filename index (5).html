PrefabForge

Built for props, environment assets, modular kits and level-design workflows. Export, import, materials, LODs and reimport — streamlined.

GAME ART TOOL

Sprite Alchemy Studio

Stylize and transform game art.

Turn source images into stylized UI/HUD elements, sprites and game-ready textures. Add outlines, glow, shading and seamless animated FX, then export static PNGs, sprite sheets or Unity-ready animation packages.

STYLIZE

Built for game-art workflows

Use ready-made visual styles, then fine-tune color count, highlight reduction, softness and stylization only when needed.

ANIMATE

Loop-safe animated FX

Create mist, vapor, flames, poison and spectral flows around UI or sprite silhouettes without resampling the finished artwork.

EXPORT

Ready for Unity

Export an animated package and let the Unity importer build sliced sprites, an AnimationClip, AnimatorController and ready prefab.
