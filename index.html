What PrefabForge does

PrefabForge is a two-part pipeline: an app that runs inside Unreal and a plugin that runs inside Unity. The goal is simple: select an Unreal/Fab asset, export it, then import it as a Unity-ready prefab.

Step 1
Select in Unreal

Choose a Static Mesh or Material. No Unreal technical setup required for normal use.

Step 2
Forge export

PrefabForge converts materials, prepares textures and optimizes heavy meshes.

Step 3
Import in Unity

The Unity plugin rebuilds the prefab, materials, textures and LOD setup.

Step 4
Repair if needed

Material Re-Forge fixes rare cases like glass, decals, foliage or opaque overrides.

Designed for Static Mesh assets

PrefabForge v1.0 focuses on props, modular kits, environment pieces and level-design assets from Unreal or Fab.

Install PrefabForge in Unreal

Use the PrefabForge Unreal package that matches your Unreal Engine version. These are the supported compiled versions.

UE 5.4 UE 5.5 UE 5.6 UE 5.7 UE 5.8
  1. Close Unreal Engine.
  2. Open your Unreal project folder.
  3. Copy the PrefabForge Unreal package contents into the project.
  4. Open the project again.
  5. If Unreal asks to enable plugins, enable them and restart.
  6. Open PrefabForge from the toolbar or from the PrefabForge menu.

Required Unreal plugins

PrefabForge needs Unreal's editor scripting features. The first-run setup should check these automatically.

✓
Python Editor Script Plugin
Required so the PrefabForge app can run inside Unreal.
✓
Editor Scripting Utilities
Required for editor asset operations.
✓
Geometry Script
Required for High Fidelity material bake workflows. Normal Fast PBR workflows can still be used without it. In Unreal Engine 5.4, this plugin is marked as Beta by Epic, so Unreal may show an extra warning when enabling it.
✓
PrefabForge Editor Bridge
Included with PrefabForge. Adds the embedded app tab and native dialogs.
✓
PrefabForge Thumbnail Bridge
Included with PrefabForge. Improves asset thumbnails and selected asset previews.
Unreal Engine 5.4 is the minimum supported version. Geometry Script is marked as Beta in UE 5.4 by Epic, but PrefabForge only uses it for High Fidelity bake workflows. Fast PBR export remains available without that workflow.
Do not install the wrong Unreal package. A compiled plugin for UE 5.7 is not the same as one for UE 5.4.

Install PrefabForge in Unity

The Unity side is installed like a normal Unity package. It adds the PrefabForge window and Material Re-Forge.

  1. Open your Unity project.
  2. Import the PrefabForge Unity package.
  3. Open Tools / PrefabForge / Open PrefabForge.
  4. Select the folder where Unreal exports PrefabForge assets.
  5. Import the exported asset folder.
Assets/ └─ PrefabForge/ ├─ Editor/ └─ Shaders/
PrefabForge supports Built-in Render Pipeline and URP. Auto mode chooses the correct material setup for the current Unity project.

Quick Start

Convert a Fab/Unreal Static Mesh into a Unity prefab.

  1. In Unreal, select one Static Mesh asset.
  2. Open PrefabForge.
  3. Press Forge Unity-Ready Prefab.
  4. Wait until the export finishes.
  5. Open Unity.
  6. Open Tools / PrefabForge / Open PrefabForge.
  7. Select the exported folder and import it.
  8. Drag the generated prefab into your Unity scene.
Most users should start with this workflow. Only use advanced material options if the result needs extra visual recovery.

PrefabForge for Unreal

This is the app that runs inside Unreal. It prepares assets for Unity.

Forge Unity-Ready Prefab

The main button. Use it for Static Mesh assets such as props, modular pieces, environment assets and level-design meshes.

  • Exports the mesh.
  • Optimizes heavy Nanite assets for Unity.
  • Exports textures and material data.
  • Creates a folder the Unity plugin can read.

Forge Unity-Ready Material

Use this when you only want to convert a selected Unreal material into Unity-ready texture maps.

  • Bakes material appearance.
  • Exports usable Unity texture maps.
  • Useful for reusable surface materials.

Nanite Optimization, in normal words

Many Fab/Unreal assets are built for Unreal's Nanite system and can be too heavy for Unity. PrefabForge automatically chooses a safer Unity mesh detail value when it detects one of these assets.

You can still increase detail manually if the asset is a close-up hero prop, or lower it if you need more performance.

PrefabForge for Unity

This is the plugin that imports the folder exported from Unreal and rebuilds the asset in Unity.

Creates prefabs

Generates a scene-ready Unity prefab from the exported asset.

Builds materials

Creates Built-in or URP materials from PrefabForge metadata.

Configures textures

Sets normal maps, packed maps, alpha and texture import options correctly.

Handles LODs

Creates Unity LOD setup when the Unreal export includes LOD meshes.

Material Re-Forge

Material Re-Forge is the manual repair tool in Unity. Use it when a material imports but does not look right.

Use thisWhen
Recover ImportedYou want PrefabForge to rebuild the material from the exported metadata.
OpaqueThe asset looks transparent/glassy but should be solid.
GlassThe material is real glass, dirty glass or transparent panels.
FoliageLeaves, plants, thin cards or two-sided vegetation.
Decal Fade / CutoutDecals, labels, stains, leaks or masked overlays.
Simple rule: if something looks strange, try Recover Imported. If it should be solid, use Opaque.

Troubleshooting

Unreal says the plugin was built for another version

Install the PrefabForge package that matches your Unreal version.

PrefabForge does not appear in Unreal

Check that the PrefabForge folders are inside your project and that the required Unreal plugins are enabled.

Unity material is pink

Make sure the correct render pipeline is active. URP projects need URP installed and configured.

A material imported as glass/mixed but should be solid

In Unity, open Material Re-Forge and apply Opaque.

The Unity import cannot find the asset

Import the complete PrefabForge export folder. Do not move only the FBX or only the textures.
