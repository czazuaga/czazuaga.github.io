Sprite Alchemy Studio

Sprite Alchemy Studio is a focused desktop tool for turning source images into stylized game art. It is built for UI/HUD elements, sprites and texture workflows, with optional finishing effects, seamless animation and a fast Unity export pipeline.

Quick Start Effects Animation Unity Importer

What it does

The normal workflow is intentionally short: import, choose a visual style, stylize, finish, animate if needed, then export.

STYLE

Stylize artwork

Use ready-made rendering styles for cleaner, darker, retro or pixel-oriented results.

FINISH

Add effects

Add outlines, outer glow, inner glow and optional shading without changing the base style recipe.

ANIMATE

Create seamless FX

Build loop-safe mist, vapor, flames, poison and spectral movement around finished artwork.

EXPORT

Ship game-ready files

Export static PNGs, sprite sheets, PNG sequences or a Unity-ready animated package.

Quick Start

Create a stylized UI or sprite asset in a few steps.

  1. Open Sprite Alchemy Studio and click Import Files or Import Folder.
  2. Under 01 · Asset, choose UI / HUD Elements for visible artwork such as icons, frames, logos or sprites.
  3. Under 02 · Style, choose a rendering style. Clean Matte is a good neutral starting point.
  4. Under 03 · Output, choose the final resolution. The preview can stay at 2× for easier inspection.
  5. Press Stylize Selected in 04 · Process.
  6. Open the Effects tab if you want outline, glow, inner glow or shading.
  7. Open Animation only if the asset needs a seamless animated effect.
  8. Use 05 · Export to export the selected result, all styled assets, or a Unity package.
Recommended workflow: start with a preset and only open manual controls when the result needs adjustment. Sprite Alchemy is designed to work well without tuning every parameter.

Installation

The public Windows build is portable and does not require Python.

  1. Download the Sprite Alchemy Studio Windows release.
  2. Extract the complete ZIP to a normal folder.
  3. Run Sprite Alchemy Studio.exe.
  4. Keep the full extracted folder together when moving or backing up the application.
Projects are stored as lightweight .sasproj files. Source images are referenced from disk rather than embedded into the project file.

Asset Types

Choose this first. It controls whether Sprite Alchemy may reframe the visible artwork or must preserve the technical texture layout.

UI / HUD Elements

For icons, logos, HUD frames, buttons, sprites and other visible artwork.

  • Fits visible artwork proportionally inside a square canvas.
  • Supports Effects.
  • Supports Animation.
  • Supports Export for Unity.

Texture / UV Safe

For technical textures where layout and normalized UV positions must not move.

  • Preserves source aspect ratio and layout.
  • Does not crop, center or reframe the texture.
  • Effects and Animation are disabled.
  • Use this for materials and UV-sensitive texture work.
If a texture changes position or framing when it should not: switch the asset to Texture / UV Safe and stylize it again.

Effects

Effects sit on top of the base stylization. You can use a preset or open manual controls only when needed.

Effects Presets

Choose a ready-made effect family such as Magic, Poison, Holy, Fire, Spectral or one of the atmospheric/noise variants. Custom effect presets can also be saved for reuse.

Outline

Color, thickness, softness, position and opacity. Outside is the standard game-art outline mode.

Outer Glow

Color, size, softness, brightness and visual style. The glow is always rendered behind the asset.

Inner Glow

Adds controlled light or color inside the visible silhouette.

Shading

Contains Drop Shadow, Tint / Colorize and Edge Light.

FX sizes scale with output resolution, so a preset authored at a smaller size remains visually consistent when exporting larger versions.

Animation

Animated FX are designed as seamless loops around the already-styled artwork. The static artwork stays 1:1 and is not reprocessed for every frame.

Animation modes

Arcane Flow

Directional procedural flow around the silhouette. This is the main animated mode.

Pulse Only

A simple external pulse without a flowing smoke field.

Flicker Only

A simple looping external flicker.

The flow emitter follows the full exterior contour of the asset. Upper edges emit most strongly, while side and lower exposed areas can still contribute, so gaps under tails, limbs or decorative silhouettes do not become dead zones.

Play renders and previews the current loop. Stop can stop playback and can also cancel loop rendering between frames.

Animation output

  • Export Spritesheet writes the full loop to one image.
  • Export PNG Sequence writes one PNG per frame.
  • The exported loop does not duplicate the first frame at the end.

Projects

Use projects when you want to keep several assets and their settings together.

  • Project files use the .sasproj extension.
  • Each asset keeps its Asset Type, Rendering Style, Output, Effects, Animation and styled-result state.
  • Recent Projects are available from the File menu.
  • Autosave/recovery protects work in progress.
  • Missing source images can be relinked.
  • Source images are referenced, not embedded, so moving the source files may require relinking.
An empty new project is not treated as modified just because you looked at or changed controls. Sprite Alchemy only asks to save when there is actual project content/state worth preserving.

Unity Importer

Sprite Alchemy Studio can export an animated asset package that the companion Unity Importer turns into native Unity assets automatically.

Install the importer

Copy into Assets

Copy the complete SpriteAlchemyUnityImporter_1.0.2 folder anywhere under your Unity project's Assets/ folder.

Package Manager

Use Window → Package Manager → + → Add package from disk... and select the importer's package.json.

The importer does not require Unity's optional 2D Sprite package.

Export from Sprite Alchemy

  1. Select a UI / HUD Elements asset.
  2. Enable and configure Animated FX.
  3. Use Export for Unity.
  4. Sprite Alchemy writes a spritesheet and a .spritealchemy.json manifest.
MyAnimatedAsset_SpriteAlchemyUnity/ ├─ MyAnimatedAsset_spritesheet.png └─ MyAnimatedAsset.spritealchemy.json

Import in Unity

  1. Open Tools → Sprite Alchemy Studio → Import Animated Asset....
  2. Select the exported .spritealchemy.json.
  3. Choose SpriteRenderer, UI Image or UI Button.
  4. Press Import & Build Prefab.

The importer creates sliced sprites, an AnimationClip, an AnimatorController and a ready prefab.

SpriteRenderer

For world-space 2D assets, effects, pickups or sprites.

UI Image

For animated images inside a Canvas.

UI Button

Creates RectTransform + Image + Button + Animator. Place it under a Canvas and connect its OnClick event.

Texture Max Size

The importer automatically sets Unity's Max Size to the smallest supported power-of-two that can contain the spritesheet before slicing it.

1536 → 20483000 → 40968192 → 8192
Spritesheets larger than 16384 px on the longest side are rejected instead of being silently downscaled. Reduce frame size or frame count and export again.

Troubleshooting

Effects or Animation are unavailable

Check 01 · Asset. Effects and animation are available for UI / HUD Elements, not for Texture / UV Safe.

Transparent edges have a dark or colored fringe

Open the Style tab and enable Transparency Cleanup. If the fringe is difficult, also try Stronger edge recovery.

A technical texture was cropped or reframed

Use Texture / UV Safe and stylize the source again.

A project opens with missing source images

Use the missing-source relink workflow. The .sasproj stores source paths rather than embedding source image data.

Unity says the spritesheet is too large

Keep the longest side at or below 16384 px. Lower the Sprite Alchemy output resolution or reduce Loop Frames.

The Unity importer is not visible

Confirm the importer folder is inside Assets/, or install its package.json through Package Manager. Let Unity finish compiling before opening the Tools menu.

Unity output looks lower resolution than the exported sheet

Use Sprite Alchemy Unity Importer 1.0.2 or newer. It automatically raises Texture Max Size to prevent Unity from shrinking the sheet before slicing.
